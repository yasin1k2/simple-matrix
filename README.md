# Simple Matrix

A simple Python program that gets a matrix from the user and calculates the sum of its rows and columns.

## Features

- Get the number of rows and columns from the user
- Get matrix elements as input
- Display the matrix
- Calculate the sum of each row
- Calculate the sum of each column

## How to Run

Clone the repository:

```bash
git clone https://github.com/yasin1k2/simple-matrix.git

cd simple-matrix

python main.py
